## 🧭 About This Log

This repo is my personal frontend dojo — where I build, break, and rebuild things using nothing but **HTML, CSS, and JavaScript**. No frameworks, no shortcuts. Just raw fundamentals, repetition, and curiosity.

Every folder here is a checkpoint in the journey: a concept learned, a bug fought, or a small project shipped.
